How this model works

  1. Read labelled examples from data/traffic_patterns.csv.
  2. Split the data into training and holdout test sets.
  3. Train a new Random Forest model on the training rows.
  4. Report holdout accuracy and classify current vehicle records.
  5. Save the fitted model to models/traffic_pattern_rf.joblib.

The model retrains when this page is opened. Accuracy on synthetic sample data does not establish real-world performance.
