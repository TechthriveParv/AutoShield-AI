# AutoShield AI — local vehicle intelligence demo

## Engine-intelligence upgrade
- Preloaded fictional vehicles with saved baseline odometer and maintenance inputs
- Add Vehicle form for user-created records
- Start Inspection workflow that pre-fills readings from the selected vehicle
- Saved inspection history linked to vehicle records
- Inspection detail reports and engine analytics charts based on saved inspections
- Safe SQLite schema migration adds new columns/tables without deleting existing vehicle records

The engine prediction dataset is synthetic. Risk and remaining-distance values are experimental demonstrations, not verified mechanical diagnoses. Do not use them for safety decisions. The app does not read ECU/OBD sensors or independently verify fault codes.

## Features
- Vehicle registration search and fictional vehicle profiles
- Fictional insurance, PUC, accident, and violation history
- Add observations and update review status
- Traffic image upload saved for human review (no pretrained image detector)
- Analytics charts, expiry watchlist, data quality flags and audit log
- CSV and PDF report downloads
- **Random Forest ML Insights**: train a supervised classifier from `data/traffic_patterns.csv`, evaluate it on a holdout split, classify local vehicle records, and show feature importance
- Dark/light theme; SQLite database auto-created with fictional seed data

## ML model and dataset
This version uses a `RandomForestClassifier` from scikit-learn, trained locally from scratch each time the ML Insights page is opened. It does not use YOLO or download a pretrained model. The labelled dataset is `data/traffic_patterns.csv`.

The included CSV is **synthetic demonstration data**, not real traffic history. Replace it with your own reviewed and labelled dataset before making real-world claims. Required columns:

- `vehicle_age`: age of vehicle in years
- `violations_90d`: number of recorded observations in the last 90 days
- `accidents_365d`: number of accident records in the last 365 days
- `pending_reviews`: number of observations awaiting human review
- `insurance_expired`, `puc_expired`, `registration_expired`: 0/1 flags
- `traffic_pattern`: human-reviewed target label, e.g. `Routine`, `Monitor`, `Priority Review`

Random Forest is supervised classification, not unsupervised clustering. The target labels must be provided in the training CSV. Define the labels consistently with your supervisor/domain expert; they are record-review categories only, not proof of an offence, driver behaviour, or legal/safety risk. Do not train/evaluate using labels mechanically derived from the same exact features if you want independent evidence of predictive performance.

The model uses a train/test split and reports holdout accuracy, class distribution and feature importance. Metrics from synthetic data are only a software demonstration. Use a sufficiently large, representative dataset and preferably cross-validation before drawing conclusions. Avoid including personal identifiers such as owner names or registration plates in training features.

## Windows setup
Recommended: Python 3.11 or 3.12 (use a version supported by the installed pandas/scikit-learn wheels).
1. Extract ZIP.
2. Open Command Prompt in `AutoShieldAI`.
3. Run:
   ```bat
   python -m venv venv
   venv\Scripts\activate
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   python app.py
   ```
4. Open `http://127.0.0.1:5000` and choose **ML insights** in the sidebar.

The database `autoshield.db` is created on first run. To reset all demo data, stop the server and delete that file (back it up first).

## Routes
`/` dashboard · `/vehicles` registry · `/vehicles/add` add vehicle · `/inspections` start and review inspections · `/engine-analytics` engine charts · `/engine-forecast` legacy forecast · `/analytics` legacy fleet charts · `/reports` exports · `/health`

## Limitations
Seeded records are fictional. This app does not connect to RTO, police, e-challan, insurer, or accident databases. No plate OCR or automated traffic-offence detection is included. Human review is required. This starter is for local demonstration, not public deployment.


## Engine Health Forecast (demo)
The Engine forecast page looks up fictional vehicle records in the local SQLite database and accepts odometer/service/engine-fault inputs. It trains a Random Forest classifier for maintenance-risk categories and a Random Forest regressor for remaining engine kilometres. The bundled `data/engine_health_training.csv` is synthetic and its labels are generated by a demonstration formula. The model outputs and metrics are for demonstrating an ML workflow only, not real-world automotive advice. Replace it with appropriately sourced, labelled maintenance/failure records before making real predictive claims.

Run on Windows: `python -m venv venv`, `venv\Scripts\activate`, `python -m pip install -r requirements.txt`, then `python app.py`. Open `http://127.0.0.1:5000/engine-forecast`.
